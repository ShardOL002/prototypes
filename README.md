# CHEM Prototype

Redesigned first prototype for CHEM's JEE Main Chemistry website.

## Included

- `index.html`: single-file prototype with home, syllabus, chapter, practice, revision, and progress surfaces

## Live deployment

- Repo: `https://github.com/ShardOL002/prototypes`
- GitHub Pages: `https://shardol002.github.io/prototypes/`

## Visual direction

- Cinematic chemistry "war room" landing experience
- Stronger branch differentiation for Physical, Organic, and Inorganic Chemistry
- More aggressive chapter, practice, revision, and analytics presentation

## Notes

- The prototype follows the approved `CHEA-20` first-prototype plan.
- The spotlight chapter is `Mole Concept` to show one strong end-to-end study loop before scaling further.
